# 🔮 Electronic Grimoire — Focus Training App

A techno-spiritual focus training application powered by a live **Transformer attention simulation** and **synesthetic audio feedback**.

## What It Does
- Simulates a multi-head self-attention Transformer in real time (no external dependencies)
- Tracks mental alignment via a cosine similarity metric (the "Meditation Object")
- Applies entropy sharpening (attention regularization) to counteract drift
- Plays synesthetic audio tones via the Web Audio API (the "Ethereal Choir")
- Displays a live OMARG feedback terminal and alignment history graph
- Includes a **Live Protocol Checklist** tracking 10 Tier-1 focus principles

## Architecture
| File | Role |
|------|------|
| 	ransformer.js | Math engine — attention, FFN, cosine alignment |
| simulator.js | State machine — OMARG feedback loops, phase timer |
| choir.js | Synesthetic audio — Web Audio API synthesis |
| canvas.js | Network visualization — attention map, alignment graph |
| style.css | Dark glassmorphism UI |
| index.html | Dashboard layout & wiring |

## Quick Start
1. Clone or download the repo
2. Open index.html in any modern browser (no build step needed)
3. Click **⚡ ACTIVATE THE GRIMOIRE**
